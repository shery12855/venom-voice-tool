# Venom Voice Tool

AI voice cloning + text-to-speech tool that runs free on Google Colab (T4 GPU).

## How to run

1. Open the notebook (`Venom_Voice_Tool.ipynb`) in Google Colab.
2. Runtime → Change runtime type → GPU (T4).
3. Run **Step 1** — enter your Gmail in the box, then select the same account in the Google sign-in dialog.
4. Run **Step 2** — the tool installs and your studio link appears in this step (about 3–4 minutes).

## Access

Only Gmail addresses on the owner's access list can run this tool. If your Gmail is not on the list, Step 1 will stop and the tool will not launch — contact the owner to get access.
